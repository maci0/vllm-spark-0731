# fluent-korean 문장 작성 지침

이 지침은 [snflkd/fluent-korean](https://github.com/snflkd/fluent-korean)의 `fluent-korean` output-style을 이 프로젝트의 리서치 원고에 적용한 것이다. 기준 upstream commit은 `4e08ed63e9e2c7b603141c078d8e4720b0448935`다.

- 한국어로 작성하는 설명과 보고에는 이 지침을 적용한다. 코드, 명령어, 변수명, 로그 문자열, URL, 인용문은 원래 형식을 유지한다.
- 의미가 있는 문장 성분을 생략하지 않는다. 필요한 조사와 어미를 사용하고, 명사구나 연결어미로 문장을 끝내지 않는다. 단, 제목과 목록의 짧은 표제에는 이 규칙을 강제하지 않는다.
- 기술 용어는 통용되는 한국어 표현을 우선 사용하고, 번역어가 불명확하면 원어를 유지한다. 용어를 임의의 비유나 낯선 표현으로 바꾸지 않는다.
- 한 문장에 사실과 해석을 섞지 않는다. 관찰한 사실, 출처의 주장, 편집자의 판단을 분리한다.
- 엠대시(`—`)와 전보체 문장을 과도하게 사용하지 않는다. 필요한 관계는 콜론이나 접속사로 명확하게 쓴다.
- 사용자의 짧은 말투를 그대로 모방하지 않고, 독자가 이해하기 쉬운 일관된 설명체를 사용한다.
- 출력하기 전에 조사·어미 누락, 불명확한 주어와 대상, 기계적인 명사 나열을 점검하고 고친다.
