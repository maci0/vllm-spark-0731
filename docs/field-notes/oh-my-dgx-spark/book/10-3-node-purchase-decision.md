# 10-3. 노드 수별 구매 판단

이 페이지는 [10-1. 비용·전력·구성 의사결정](10-1-cost-power-decision.md)의 상세 내용입니다.

노드 수는 모델 크기만으로 결정하지 않는다.

| 구성 | 적합한 질문 |
|---|---|
| 1대 | 단일 사용자, 개발 보조, 간단한 agent |
| 2대 | 큰 context·모델 수용, TP/DP 비교 |
| 3~4대 | topology와 동시성 확장 |
| 6~8대 | 팀 서비스와 클러스터 운영 |

한 대에서 목표 workload를 아직 정의하지 않았다면 여러 대를 먼저 사지 않는다. 반대로 단일 Spark의 메모리 한계가 명확하고 요청 수가 늘면, 두 대·네 대의 통신 비용을 benchmark로 확인한다.

구매 결론에는 “몇 대가 가장 빠른가”보다 “어떤 workload에서 언제 손익분기하는가”를 적는다.
